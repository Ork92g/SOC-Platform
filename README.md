# 🛡️ Sentinel SOC Platform

## 👨‍💻 Author

Or Kadosh

SOC Analyst Portfolio Project

Built with:

Next.js • TypeScript • TailwindCSS

A Security Operations Center simulation platform built for SOC Analyst portfolio demonstration.

The project simulates a real SOC workflow:
- Alert monitoring
- Incident investigation
- IOC hunting
- MITRE ATT&CK mapping
- Analyst actions tracking
- Security dashboard analytics


## 🚀 Features

### 📊 SOC Dashboard

- Security metrics overview
- Incident statistics
- Alert statistics
- IOC tracking
- Analyst activity
- System health monitoring
- Severity analytics chart


### 🚨 Alert Management

- View security alerts
- Investigate suspicious activity
- Create incidents from alerts
- Track alert severity and source


### 🔬 Incident Response

- Incident details page
- Severity classification
- Status management
- Analyst notes
- Investigation timeline
- Response actions history


### 🎯 Threat Hunting

- IOC investigation simulation
- IP / Domain tracking
- Risk classification
- Investigation history


### 🧩 MITRE ATT&CK Integration

Mapped techniques:

- T1059.001 - PowerShell
- T1078 - Valid Accounts
- T1105 - Ingress Tool Transfer
